# 1.4.0：出发准备台

2026-10-14，在1.3.0（23cd360）上继续委托协助开发。原作者资料、地图与各模块保留；新增功能全程在本机运行，没有消耗作者API。

- 个人出行：填写出发/预计到校日期、时间、交通方式、已分配的宿舍区域与备注；保存后显示个人出发倒计时，区分未来、当天、已过日期。不推断学校报到日或接站安排。
- 行李单：15种参考物品、4类，数量1–99，待准备/已装好/到校购买/不需要；重要证件仅允许待准备或已装好。可补充20种物品，移除时确认。数量初值1可编辑，不声称是学校规定。
- 查漏补缺：读取真实清单和最近一次演练选择，显示重要证件、待核对事项、已练但需复习场景。不提供安全分或完成注册判断。
- 任务与地图衔接：从物品或核对项打开现有任务编辑器，亲自确认保存；准备默认个人出发日，购买默认预计到校日，日期可改。同标题任务打开原任务。已保存宿舍区域可在现有地图中定位。
- 出发备忘卡：汇总已保存出行、物品状态与数量、未确认清单、待复习场景、探索行程，导出TXT或预览打印。未保存草稿不进入卡片。
- 独立备份：准备台JSON先校验预览，确认后替换本模块出行与行李。取消不修改；恢复不更改问答、清单、任务、演练和行程。完整导出也包含准备台，恢复须使用准备台专用备份。

行李内容由现有资料结合通用打包建议整理，不是统一采购清单。照片规格、档案携带方式、床品尺寸、电脑是否需要及交通携带条件均待自行核对。SQLite新增departure_preparation表，按浏览器会话保存；revision与事务检测多页面冲突，非法备份整批拒绝。数量和状态修改后需保存单项；刷新离开会提醒未保存修改。

## 三分钟演示

1. 填写自己的出行日期、到校时间和宿舍区域，保存查看倒计时。
2. 身份证设已装好，毛巾设到校购买、数量2，补充眼镜盒；刷新检查保留。
3. 从毛巾安排购买任务，核对日期后保存；在地图查看宿舍区域。
4. 导出或预览打印备忘卡。导出备份，重新选择查看预览，再取消或确认恢复；确认其他模块记录保留。
