# 界面方向

面向河南科技职业大学新生，主要任务是问清资料、找到地点、完成报到准备。保留校园场景与真实资料，不采用营销页结构。

- 色彩：校园绿 #164c47、交互青绿 #24786f、白 #ffffff、浅灰绿 #eff4f3、正文 #203837、资料提醒琥珀色 #855615。
- 字体：本机中文界面字体 Microsoft YaHei UI / Segoe UI；正文16px，首屏标题34px，辅助信息13px。避免在线字体依赖。
- 布局：桌面左侧固定导航，问答主栏与报到引导辅栏；移动端收为顶部导航。聊天、地图、清单和资料均可用地址参数直达。
- 视觉重心：可输入的问答区域与实际四步报到流程。编号只用于有先后顺序的路线。
- 交互：显示检索状态、引用原文、适用范围、保存反馈；清单进度来自SQLite真实状态。地图提供缩放按钮与地点列表，兼顾键盘和移动端。
- 校核：可见焦点、减弱动画、文本换行、错误状态和原生表单语义；使用界面截图验证。
