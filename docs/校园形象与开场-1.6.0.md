# 校园形象与开场（1.6.0）

用户提供学校形象图，要求以线条展示角色，并将完整人物虚化放进背景。本轮在1.5.0外观系统内实现；新增内容为素材、开场编排、内置背景和相关验证。

## 使用

右上角“外观” → “自定义” → 内置科技背景选择“校园形象 · 线与海”。人物使用完整构图，背景模糊0–12像素、遮罩35%–85%及位置可调。新浏览器默认内置选项为校园形象，显示模式仍为浅色；已有网格、极光、自选图片及参数继续保留。选择内置方案会直接切换到该背景，保留已保存的个人图片供再次使用。

角色素材库共14款：4款原画（伸手邀请、转身挥手、坐姿阅读、迈步引导），6款Q版（欢迎见面、坐下阅读、背包出发、校园指路、好奇思考、跃起庆祝），4款表情与视角（侧脸专注、仰头大笑、惊喜回眸、课间小憩）。后四款分别采用侧面低头、闭眼仰头、背身转头和趴桌俯视构图，按情绪重绘眼睛、眉毛及嘴型。新默认角色为坐姿阅读，旧主题参数保留。点击素材缩略图即可切换开场及校园形象背景；“查看所选素材”打开完整大图，“下载这张PNG”保存透明素材。

开场约4.2秒，每种姿势自己的真实SVG轮廓依次绘出，2.3秒后淡入彩色完整角色。伸手邀请1081条、坐姿阅读1161条，全部数据见mascot-assets.json。开场与所选背景相互独立，浅色/深色也能看到角色开场。每标签页首次打开播放，可点击“跳过，进入指南”或按Esc；刷新和页面切换不重播。外观设置可关闭或“预览开场动画”。减少动态效果时自动跳过，手动预览显示静态彩色画面。无音效或持续循环。

## 素材与实现

- 来源：用户提供的cc40c856-c28c-41ab-9f46-27a2a81b2d16.png学校形象参考。未额外宣称校方核定本轮衍生素材或角色名称。
- 使用内置imagegen提取透明角色，并生成3种新原画姿势、6种Q版日常与4种不同表情/头部视角。去除原版式文字、细节栏及外部场景，保留主要人物特征；腿部、重心及服饰随新动作调整。属于生成的衍生素材，不能当作原图逐像素复制。
- 最终PNG：frontend/assets/school-mascot.png，1122×1402，RGBA透明；SHA256：14954dd7ba9833ada6e5b508b5107b1322b5636694f2c53fba2933e9f87fa49d。
- 完整生成提示词见mascot-asset-provenance.json、mascot-pose-prompts.json、chibi-asset-prompts.json和creative-asset-prompts.json；14款素材的大小、透明范围、路径数及SHA256见mascot-assets.json。未使用CLI/API密钥制作图片，项目仍拒绝原交接密钥。
- tools/build_mascot_outline.py只读取PNG分析边缘，输出代码原生SVG路径数据mascot-lines.json，不修改PNG。开发者重建轮廓需Pillow/NumPy；运行用户无需第三方依赖或重建素材。
- 页面一次加载本机轮廓数据并缓存，分批路径使用stroke-dashoffset绘制；彩色图与线条均contain对齐完整身体。路径批量插入，退出时停止动画；没有持续绘制循环。
- 素材不可用时保留欢迎文案；有轮廓无彩色图则保留线条，只有彩色图则静态显现，均可跳过且有最长4.6秒退出边界。
- 仅公开固定PNG与轮廓JSON的静态白名单映射；个人图片不上传、不写SQLite、不随指南备份导出。

## 动效审核

范围为本轮外观设置、开场和背景；原生HTML、普通CSS及JavaScript。排版、表面/触控目标、动画、图标与性能都检查了对应改动：正文层次可读、Skip至少44px、无新增图标体系、路径只在短开场绘制、素材加载与取消可以中断。

发现并修复：初版背景过淡，移除重复遮罩并降低正文容器透明底色；同时保留表单底色。图像失败隐藏破图元素，保留可退出欢迎页。未增加持续呼吸、闪烁或循环扫描：会重复吸引注意；未使导航/输入跟随开场动画：会干扰日常使用。此次范围无待修复的界面问题；全设备帧率仍未验证。
