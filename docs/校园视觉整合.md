# 校园视觉整合

2026-10-15，基于 1.6.0 的工作版本。用户纠正：参考形象用于建立背景及整套界面的视觉语言；开场由设计者确定并默认播放，不应让新生选择角色姿势。

## 当前行为

- 深蓝 `#244b85`、白色和浅蓝 `#bed9f4` 构成主色，红色 `#ca4d43` 用于桥形、飘带及小面积强调。水波、飞鸟和桥形用原生 SVG 重绘，应用到标题和背景。无新增依赖或外部请求。
- 日常页面移除角色选择、素材大图/下载入口、内置背景选择和开场开关。原有 14 款 PNG 与出处记录保留为设计资产，没有再生成或修改人物图片。
- 统一开场固定为原始邀请姿态，描线后显色。标签页首次进入自动播放约 3.6 秒（加载等待最多增加 400 毫秒），Esc 或按钮立即跳过；刷新、切换功能不重播。设置中保留“重播开场动画”。
- 尊重系统减少动态效果；手动重播显示静态完整画面。素材缺失仍能进入指南。内嵌浏览器可能延后动画绘制，2.5 秒明确切换到显色状态，避免停在首帧。
- 显示模式、本地图片、模糊、遮罩和位置继续兼容。旧姿势、背景预设与动画开关不再控制展示。未修改业务记录的保存或恢复逻辑。

范围：原生 HTML/CSS/JS 的主题、背景、设置、开场及响应式行为。按 [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md) 检查适用项。用户要求的描线使用 stroke-dashoffset，其余动效为 transform/opacity。

| 类别 | 证据 | 结果 |

| 排版 | 桌面/手机截图，标题、导航、欢迎文字 | 统一中文系统字体；修正导航换行；欢迎文字避开深色波纹 |
| 表面 | 浅色/深色页面与设置 | 复用原组件，装饰与阅读区域分层 |
| 动画 | 实际开场、跳过、8 项状态回归 | 默认一次播放，可中断，有显色及退出时限 |
| 图标 | 保留原图标；新 SVG 图案 | 装饰 aria-hidden，不拦截点击 |
| 性能 | 请求和初始化代码 | 按功能页加载插图，标题与同款背景复用路径；同标签再次进入不重复准备开场描线；无循环动画或外部请求 |

| 严重度 | 位置 | 修改前 | 修改后 | 原因 |
| --- | --- | --- | --- | --- |
| MEDIUM | appearance.js / index.html | 选择 14 姿势决定开场；日常页面仍是绿色 | 统一蓝白红界面、固定开场 | 符合用户的整体视觉要求 |
| MEDIUM | appearance.css | 中间断点负边距溢出；手机字落在深波纹上 | 断点对齐、波纹限于人物区域、浅底校训 | 避免横向滚动和低对比 |
| MEDIUM | appearance.js | 内嵌浏览器可能延后 CSS 绘制 | 定时切换完整画面并按时退出 | 防止停留首帧 |
