## 可实际使用的新功能

| 使用场景 | 1.2.0行为 |
|---|---|
| 收藏社团后不知道怎么行动 | 将对应3条建议生成待办，保留资料关联；重复生成不覆盖已完成任务 |
| 想安排下周的小目标 | 自己填写日期、优先级、备注，切换待办/进行中/完成；可留空日期 |
| 任务已经不打算进行 | 归档后可恢复为待办，记录仍保存 |
| 想检查遗漏 | 显示7天日程和已过计划日数量，按日期、进度、优先级或关键词筛选 |
| 想放进手机日历 | 导出全天ICS，包含有日期的未完成任务；由使用者在日历应用导入 |
| 想恢复到另一会话 | 导出JSON任务备份，校验并预览新增/跳过数，再事务合并；现有进度保留 |
| 资料不能确认今年日期 | 保留未知提醒，提供学校官网、固定主题的学校站内搜索及相关主办方入口 |

最多保存100项任务（包括归档）。任务仅代表个人安排，不代办报名、床位预订或加入组织。网页提醒只在页面展示，没有账户、云同步或后台推送；日历应用提醒需自行设置。当前未测试真实日历应用导入，不声称所有日历客户端兼容。

备份只恢复任务，完整记录JSON也含任务；不会自动恢复对话、报到清单、偏好或浏览器会话入口。手动任务按完整用户字段去重，关联任务按来源选项和建议序号去重。导入重新生成ID，未知来源、非法日期、异常类型或超限整批拒绝，不部分写入。
