# 1.5.0：自定义背景与开场动画

2026-10-14，在1.4.0（034f174）上按使用者要求增加第三个外观模式与开场动画。浅色和原深色继续保留，不改动校园资料、地图地点和个人指南记录。

## 使用

点击页面右上角“外观”，或桌面侧栏“外观与背景”。选择浅色、深色、自定义；设置即时应用并自动保存。

自定义采用冷蓝科技配色、静态网格或极光背景、清楚的阅读面板。可以选择自己的JPG/PNG/WebP（最多10MB，3600万像素以内），设置遮罩35–85%、模糊0–12像素、顶部/居中/底部。选择内置背景会保留图片，随时可切回；移除图片需确认，其他指南数据保留。

开场动画约2.4秒，标志、标题和引导文字依次出现。每个标签页首次打开播放，刷新和站内切页不重复。点击“跳过，进入指南”或按Esc立即进入；可关闭、手动预览。系统减少动态效果时自动跳过，手动预览是静态画面。开场没有音频、假进度或真实联网加载声明。

## 本机存储与边界

外观配置使用localStorage，图片经浏览器解码、缩放到最长边不超过2560像素并转换为JPEG，存入本浏览器IndexedDB；图片不上传到Python服务，不包含在交付包中。Blob URL只供当前页面显示，更换时释放旧URL。图片装载与更新区分版本，避免旧读取覆盖新选择。

背景与配置属于浏览器当前站点，换浏览器、域名或端口、清理站点存储后需重新设置。任务或准备台备份不携带背景，不提供跨设备同步。浏览器拒绝存储时显示临时应用或图片保存失败提示，不影响指南功能；存储不可用时刷新可能恢复默认或重播开场。

仅img-src增加blob:以显示自己选择的图片；connect-src仍为self，未放宽脚本、接口或文件白名单。所有功能无需模型或图片生成API。

## 实际验证

81项离线/回环HTTP回归通过，新增外观静态资源与本地图片CSP检查。

Edge独立8770服务与虚构数据进行了15项浏览器检查：首次开场/Esc、同标签刷新不重播、本地JPEG保存与调整、刷新恢复、三模式切换、损坏及超10MB图片保留旧背景、非法配置归一化、关闭开场后新标签不播放、预览返回焦点、确认移除、真实指南记录保持、390px页面/弹窗无溢出、减少动态效果、继承旧深色偏好、偏好存储不可用的提示。无console警告/错误，remote_calls=0。报告为appearance-browser-verification.json。
