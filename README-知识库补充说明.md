# 知识资料说明（接手版）

本文件取代交接包内的旧入库步骤。原说明保存在 Git 基线提交 `969ca1e`，用于查看接手背景。

当前应用读取根目录14份固定资料，启动时直接建立本地检索索引，无需虚拟环境、D盘目录、Chroma 或联网下载模型。完整启动方式见 [README](README.md)。资料修改后重启服务即可。

```powershell
python -X utf8 -S run.py
```

可选的 `python -X utf8 -S backend/scripts/ingest.py` 只检查本地资料切分，不进行联网入库。

资料标题或交接说明中写有“官方”，只表示交接文件所声称的来源，不能证明本轮已核对其内容和时效。界面统一使用以下标记：

| 标记 | 范围 |
|---|---|
| 官方入口已核对 | 官方服务入口.md，2026-10-08核对网站、地址、咨询电话及支付平台入口；不等于收费政策已核对 |
| 交接资料待核对 | 原项目中的学校概况、招生与手续等继承资料 |
| 第三方参考 | 入学准备、宿舍生活、户口、资助、军训等含第三方整理的资料 |
| 交接地图参考 | 对照收到的地图校正图上位置；年代、实地导航和开放情况未知 |

2024级参考不代表当年安排；“抓取日期”不等于适用年份。具体报到日期、接站时段、收费金额和设施开放时间仍需核对学校当年通知。当前固定 FAQ 检索指标只能说明资料能被找到，不能当作答案正确率。
