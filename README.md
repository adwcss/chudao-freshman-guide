一句话定位：面向大学新生的"**先演练 → 再探索 → 后准备**"互动入学指南。围绕报到情景批判式演练、校园地图探索行程、出发准备、成长计划与本地知识问答组成完整产品闭环。

参赛组别：**Vibe Coding 全栈应用速成挑战赛**　·　选题方向：**场景化轻量 RAG 知识库（校园场景）**

> 本文档即赛事要求的 **README / 复现性声明（含 10 分钟极速复现指南、环境配置、依赖清单、环境变量模板）**。历史变更、架构与验证数据见页尾"材料索引"，不占用复现主流程。

## 一、10 分钟极速复现（核心）

> 目标：让评委在全新机器上，从拿到源码到打开可用界面，**10 分钟内完成**。默认全程本地运行，**不需要任何 API 密钥、不需要 pip install、不需要模型下载、不需要入库**。

### 第 1 步 · 确认环境（约 1 分钟）

| 项 | 要求 | 检查命令 |
|---|---|---|
| Python | **3.10 或更新** | `python --version` |
| 浏览器 | Chrome / Edge / 现代浏览器之一 | 打开任意网址即可 |

本项目 **零第三方运行依赖**，只用 Python 标准库，因此**无需 venv、无需 requirements、无需 Anaconda tools 夹带**。

### 第 2 步 · 启动（约 1 分钟）

在**项目根目录**（含 `run.py` 的目录）运行：

```powershell
python -X utf8 -S run.py
```

> `-X utf8` 保证中文编码一致；`-S` 跳过本机额外 site 初始化，避免被其他项目污染环境。Windows 也可直接双击 `启动新生指南.cmd`。

### 第 3 步 · 访问（约 1 分钟）

浏览器打开：**http://127.0.0.1:8765/**

启动成功的标志：终端显示服务已在 `127.0.0.1:8765` 监听，页面显示问答/演练/地图等功能入口。**此时即可直接使用，不需要任何配置。**

### 第 4 步 · 抽查核心功能（约 4 分钟）

1. **知识问答**：问 *"报到需要准备哪些材料？"* → 返回分条解答 + 可展开的来源引用。
2. **诚实提示**：问 *"今年新生什么时候报到？"* → 返回"当前收录资料未确认当年时间"的明确警示，**不编造日期**。
3. **情景演练**：进入"新生情景演练"，选择任一场景 → 看到解释、建议和原文依据。
4. **地图探索**：打开"校园地图"，确认 45 个地点、区域筛选、缩放与大图可用。
5. **成长计划**：进入"我的成长计划"，调整权重 → 显示匹配理由与取舍。

### 第 5 步 · 验收自检（约 2 分钟，可选）

```powershell
python -X utf8 -I -S tools/verify.py
```

预期输出：`Ran 82 tests ... OK`（若环境无 `-I` 支持的旧版本，去掉 `-I` 重试）。再抽查检索：

```powershell
python -X utf8 -I -S tools/evaluate_retrieval.py --output docs/verification_now.json
```

### 第 6 步 · 收尾（< 1 分钟）

终端 `Ctrl+C` 停止。端口被占用时改用：`python -X utf8 -S run.py --port 8766`。

**累计约 10 分钟，无需联网、无需付费额度即可看完全流程。**

## 二、环境变量模板（默认全部关闭）

**默认不需要设置任何变量**，程序也不会读取 `.env` 文件。以下均为**可选增强**，开启前请在启动用的同一个终端设置。

```powershell
# —— 可选：接入自己的外部大模型（DeepSeek 兼容）——
# 只有在"允许开关 + 有效新密钥"同时满足时才可能发出外部请求
$env:GUIDE_ALLOW_REMOTE_LLM = 'true'
$env:GUIDE_LLM_API_KEY = Read-Host '输入你自己的新密钥'
$env:GUIDE_LLM_MODEL  = 'deepseek-chat'

# —— 可选：接入联网搜索（本地资料不足/涉时效时补充参考）——
#$env:GUIDE_ALLOW_WEB  = 'true'
#$env:GUIDE_WEB_API_KEY = Read-Host '输入你的 SerpAPI 密钥'
#$env:GUIDE_WEB_ENGINE = 'bing'

# —— 可选：指定数据目录（对话/清单/反馈 SQLite 位置），默认 .runtime ——
#$env:GUIDE_DATA_DIR = 'D:\some\path'

python -X utf8 -S run.py
```

| 变量 | 默认值 | 用途 |
|---|---|---|
| `GUIDE_ALLOW_REMOTE_LLM` | `false` | 明确允许外部模型请求的开关 |
| `GUIDE_LLM_API_KEY` | 空 | 你自己的新密钥；**交接/被拦截密钥会按指纹拒绝** |
| `GUIDE_LLM_MODEL` | `deepseek-chat` | DeepSeek 兼容模型名称 |
| `GUIDE_ALLOW_WEB` | `false` | 联网搜索开关（无 Key 也会回退本地，绝不联网） |
| `GUIDE_WEB_API_KEY` | 空 | SerpAPI 密钥，用于联网搜索补充参考 |
| `GUIDE_WEB_ENGINE` | `bing` | 可选 `bing` / `google` |
| `GUIDE_DATA_DIR` | 项目下 `.runtime` | 本地对话、清单与反馈数据库位置 |

**密钥安全红线**：不要在 README、代码、提交信息或日志中写入真实密钥，也不要提交 `.env`。脚本内最终提交版本应只保留环境变量占位。默认模式下本项目对 `api_key` 用 SHA-256 指纹做拦截，交接密钥即使被填入也会被拒绝调用。

## 四、项目结构（概览）

```text
run.py                         单命令启动
backend/main.py                本地 HTTP API 与静态页面服务
backend/answer.py              本地证据回答 / 可选 DeepSeek 适配
backend/retriever/             中文检索、文本块与来源元数据
backend/catalog.py             FAQ、地图热点、路线、准备清单
backend/experience.py          偏好校验、规则推荐、统一目录与计划动作
backend/store.py               SQLite 对话/偏好/收藏/清单与会话隔离
backend/settings.py            外部调用开关与密钥指纹拦截
config/blocked_key_fingerprints.json  交接密钥拒绝列表
tools/verify.py                82 项离线回归验收
tools/evaluate_retrieval.py    FAQ 检索评估（18/18、4/4）
frontend/                      页面界面（HTML/CSS/JS，含演练/准备台/成长计划等）
docs/                          架构、验收、迭代与演示脚本等完整材料
.runtime/                      运行数据（Git 忽略，不在仓库内）
```

**安全边界**：服务只绑定 `127.0.0.1`，拒绝陌生 Host 与跨站 Origin，上传/静态文件有白名单；不是面向公网的多用户部署版本。

## 五、资料与诚实性声明（评审可复核）

- "采集日期"不等同"适用年份"。交接资料含 2024 级内容与第三方建议，均带年份与可信度提示；程序**不会承诺**当年报到日期、接站时段、收费金额或设施开放时间，资料不足时明确提示而非编造。
- 本地模式按检索到的资料摘录回答，**不冒充大模型生成**；其目的是让评委无需付费额度即可验证完整产品流程。
- 官方服务入口、地址与咨询电话已于对照学校官网核对；其他继承资料标"待核对"，不以已验证官方事实自居。
- 特殊情况（时效问题、资料不足、收费/开放时间未知）会明确提示；联网搜索仅将结果放入独立的"网络参考"块，**不混入本地事实**，并标注"非学校官方核对"。
